## ما هو؟

**المطورين المكتملين** سكيل (`SKILL.md`) يعطي أي وكيل ذكاء اصطناعي عادات استوديو صغير: مهندس يفكّك طلبك ويفهم ما تقصده فعلاً، ومصمم يرسم قبل أن يبني ولا يخرج تصميمه بشكل آلي، ومطور يبني على شرائح صغيرة قابلة للفحص، ومدقق يعرض الدليل لا الثقة. وكل ذلك مضبوط لاستهلاك توكن قليل.

هو **أسلوب عمل** وليس بروميت سحري: يجعل ما يفعله المحترفون بصمت ظاهراً ورخيصاً وقابلاً للفحص، فتلتزم به النماذج المتوسطة باستمرار، وتختصر منه النماذج القوية ما لا تحتاجه.

## ماذا تحصل عليه؟

| الركن | ما يفعله |
|---|---|
| **فكّك (Decode)** | يحوّل «سو لي موقع لمطعم» إلى **بطاقة بروميت** (~120 كلمة): الهدف، الجمهور، المطلوب والمستبعد، الافتراضات، معايير الإنجاز. ويقدر أيضاً **يصدّر بروميت جاهز** للصقه في أداة ثانية. |
| **ارسم (Draw)** | تخطيطات للجوال والشاشة الواسعة، مخططات انسياب ومعمارية وحالات، بـ ASCII أو Mermaid أو HTML/SVG. وفي العمل الفاخر: ثلاثة رسومات مختلفة البنية ثم اختيار واحد بسبب مكتوب. |
| **خطّط (Plan)** | من 3 إلى 7 شرائح، كل شريحة تعمل وتُفحص بفحص واحد، والمجهول الأخطر أولاً. |
| **صمّم (Atelier)** | تصميم بروح بشرية: 4 مؤشرات ضبط، 15 نمطاً، قائمة بعلامات التصميم الآلي التي تُتجنب، منهج من مرحلتين، بروتوكول نقد، و**ألوان مفحوصة التباين** يولّدها سكربت. |
| **ابنِ (Build)** | يقرأ قواعد مشروعك أولاً (lint وcommit والتنسيق)، اتفاقيات أخطاء وأمان، ملاحظات للألعاب والمودات (Roblox وBedrock وويب)، ووضع ترقيع للثغرات. |
| **أثبت (Prove)** | سلّم أدلة، وكلمات حالة دقيقة: *passed / failed / not run / blocked*، ومراجعة ذاتية عالية الإشارة، وبوابة أمان. |
| **وفّر (Thrift)** | نظام اقتصاد توكن من 12 آلية: مسارات، تحميل تدريجي، خرائط مشاريع، تقليم اللوقات، تعديل بالـ diff بدل إعادة الطباعة، دفتر حالة من 40 سطراً، وقواعد إيقاف. |
| **عربي وRTL** | خصائص CSS منطقية، قواعد خط عربي، أرقام واتجاه نص مختلط، قلب الأيقونات، كتابة المحتوى، ودليل حلول للمحركات التي لا تشكّل الحروف العربية. |

## ثلاثة مسارات: تدفع فقط مقابل ما تحتاجه

| المسار | متى | الكلفة |
|---|---|---|
| **Spark** | تعديل واحد واضح أو سؤال | النواة فقط، diff، وردّ من 3 أسطر |
| **Craft** | ميزة جديدة، طلب غامض، تطبيق صغير | تفكيك ← رسم صغير ← شرائح ← فحوص |
| **Atelier** | جودة الشكل هي المنتج، أو قلت «فاخر» | كل ما سبق + ثلاثة رسومات + ميثاق تصميم + فحص كامل |

## التثبيت

</div>

```bash
git clone https://github.com/<your-user>/complete-developers
cd complete-developers
python skills/complete-developers/scripts/install.py --host claude    # أو: opencode | agents | codex | gemini | all
```

<div dir="rtl">

المثبّت ينسخ السكيل ويحتفظ بنسخة احتياطية من أي تثبيت سابق ولا يلمس شيئاً آخر. خيارات مفيدة: `--scope project` و`--mode link` (رابط رمزي، تعديلاتك تظهر مباشرة) و`--dest <مجلد>` و`--dry-run` و`--uninstall`.

التثبيت اليدوي: انسخ مجلد `skills/complete-developers/` إلى مجلد السكيلات في أداتك، ثم افتح جلسة جديدة واذكر اسم السكيل مرة واحدة. مواقع المجلدات تختلف بين الأدوات وتتغير مع الوقت؛ إن لم تكن أداتك في القائمة راجع توثيقها واستخدم `--dest`.

جرّب:

> استخدم complete-developers: سو لي موقع لمطعم

```

WHO/WHERE سكان الحي · جوال أولاً (390px) · عربي RTL · HTML/CSS/JS ثابت
MUST      قائمة بأسعار، أوقات، رابط الموقع، زر واتساب للطلب (e)، معرض صور (e)

DONE WHEN لا تمرير أفقي عند 360px · التباين ≥ 4.5 · كل زر يعمل أو يوضح سبب تعطله
ASSUMED   رقم واتساب نموذجي بتسمية واضحة     UNKNOWN ألوان الهوية
```

<div dir="rtl">

ثم ثلاثة رسومات، وميثاق تصميم مولَّد (ألوان بتباين مقاس، خطوط، مسافات، حركة)، وشرائح، وملاحظة تسليم من 12 سطراً. المثال الكامل: [examples/01-restaurant-site.md](examples/01-restaurant-site.md).

## الأدوات المساعدة (Python 3، مكتبة قياسية فقط، بلا إنترنت)

</div>

```bash
python scripts/repomap.py .                      # شجرة + عدد الأسطر + الرموز (دوال/كلاسات)
python scripts/tokencount.py src --top 10        # تقدير كلفة قراءة الملفات قبل فتحها
npm test 2>&1 | python scripts/logtrim.py        # الإبقاء على الخطأ وسياقه وطيّ التكرار
python scripts/charter.py --archetype food-hospitality --rtl --name "مطعمي"
python scripts/contrast.py "#1A1A1A" "#FAF8F3"   # نسبة WCAG
python scripts/changelog.py --version 1.2.0      # ملاحظات إصدار من Conventional Commits
```

<div dir="rtl">

كلها للقراءة فقط، و`repomap` يتجاهل أسماء الملفات الحساسة (`.env` والمفاتيح) ولا يشغّل كود المشروع.

## أفكار لا نسخ

صُمّم هذا السكيل بدراسة عشرة مشاريع مفتوحة واستخلاص **أفكارها فقط**. لم يُنسخ نص ولا بيانات ولا كود؛ الصياغة والتنفيذ أصليان. تفاصيل الأفكار في [README الإنجليزي](README.md#ideas-not-code).

## حدود صريحة

- لا يجعل النموذج أذكى؛ يجعل العادات الجيدة ثابتة. والنتيجة تبقى تعتمد على النموذج والأداة.
- التفعيل التلقائي يختلف بين الأدوات؛ ذكر اسم السكيل مرة يزيل الشك.
- **لا نعد بنسبة توفير محددة** في التوكن. العادات تزيل الهدر الشائع، وقِس مهامك بنفسك (`tokencount.py` وعدّاد الاستخدام في أداتك). الأرقام في الميزانيات نقاط بداية.
- الذوق التصميمي لا يُؤتمت بالكامل؛ الميثاق والنقد يضمنان الاتساق وتجنب الشكل الآلي، والعين البشرية هي المراجع الأخير.
